# CHANMAN. — Personal Portfolio Website

**Live:** https://portfolio-jade-xi-93.vercel.app/

My personal portfolio website — projects, background, and an online resume. Built with Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS 4, deployed on Vercel.

## ✨ Features

- **Hero landing** — full-screen intro with stylized avatar and quick navigation
- **About Me** — background, skills, and contact links (GitHub / LinkedIn / Email)
- **Portfolio** — 4 featured projects, each presented with:
  - 🖼️ Image carousel gallery (custom `ProjectGallery` client component)
  - 🏷️ Tech-stack tags, description, and highlight bullets
  - 🔗 Direct link to the GitHub repository
- **Online resume** (`/resume`) — in-browser PDF viewer powered by react-pdf + pdf.js (worker and assets bundled via a build script)
- **Responsive design** — mobile-first layout with Tailwind CSS

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router), React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Fonts:** Geist / Geist Mono via `next/font`
- **PDF:** react-pdf + pdf.js (worker, cmaps, fonts, and wasm assets copied into `public/` by script)
- **Database:** MongoDB Node.js driver (connection helper in `lib/`)
- **Deployment:** Vercel
- **Dev environment:** Docker Compose (`node:24-alpine`)

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- npm

### 1. Clone & install

```bash
git clone https://github.com/MikeC-08/portfolio.git
cd portfolio
npm install
```

### 2. Copy pdf.js assets (required for the resume viewer)

```bash
node scripts/copy-pdf-assets.cjs
```

This copies `pdf.worker.min.mjs`, cmaps, standard fonts, and wasm files from `pdfjs-dist` into `public/pdfjs/`.

### 3. Run the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production

```bash
npm run build
npm run start
```

### Docker alternative

```bash
docker compose up
```

Builds and serves the production build on [http://localhost:3000](http://localhost:3000).

## 🌐 Deployment

Deployed on [Vercel](https://vercel.com). Every push to `main` triggers an automatic redeploy.
